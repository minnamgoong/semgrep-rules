# tainted-html-string (동적 HTML 이스케이프 누락 감지)

## 개요
Response 전송 혹은 에디터 가공 명목으로 HTML을 직접 자바 코드 단에서 `String`으로 접착할 때 외부 데이터가 합사되는 것을 경보합니다.

## 위험성
*   **XSS**: 렌더링 시 악성 자바스크립트가 격트되어 구동되는 XSS 정기 피해를 초래합니다.

## 조치 방안
*   가급적 뷰 템플릿 엔진 자동 이스케이프에 위임하거나, 굳이 자바 코드라면 서드파티 이스케이퍼(`HtmlUtils.htmlEscape` 등)를 거쳐 주입하세요.
