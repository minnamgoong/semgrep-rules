# tainted-url-host (URL 호스트 가변 조작 경보)

## 개요
URL 구성의 호스트 영역(`http://[Host]/...`)을 조립할 때 소스 레이어 사용자 가변 인자가 직접 기여하는 결함을 진단합니다.

## 위험성
*   **SSRF / Open Redirect**: 가변 위치를 공격자가 자사 피싱 도메인이나 내부 로컬망 IP로 우회 발신하여 피해 복구가 힘든 2차 침투를 달성할 수 있습니다.

## 조치 방안
*   호스트 명단을 내부 Enum이나 제한된 룩업 화이트리스트 맵으로 고정시켜 사전 인코딩 필터링하세요.
