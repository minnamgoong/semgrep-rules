# tainted-file-path (파일 경로 제어 오염 위험)

## 개요
확장자 주입이나 파일 로드 시 외부 사용자의 가변 인자가 경로 인자로 조치되는 위험 패턴을 확인합니다.

## 위험성
*   **Path Traversal**: `. ./` 같은 디렉토리 탐색 특수문자로 시스템 설정 파일(/etc/hosts 등)을 취득하는 등 큰 시스템 누출 피해를 봅니다.

## 조치 방안
*   입력값 중 유해 문자열을 필터링하거나, File 인스턴스의 `getCanonicalPath()` 등을 동원해 절대 허용 상위 디렉토리 영역을 이탈하는지 사전 검증하세요.
