# jjwt-none-alg (JWT 'none' 알고리즘 사용 위험)

## 개요
JSON Web Token(JWT) 생성/검증 시 서명을 생략하는 `none` 알고리즘이 활성화된 위험을 감지합니다.

## 위험성
*   **인증 우회**: 공격자가 로컬에서 헤더의 알고리즘을 `none`으로 바꾸고 페이로드를 조작해 관리자 권한 등을 획득해도 서버가 이를 유효하게 처리할 수 있습니다.

## 조치 방안
*   서버 검증 시 반드시 암호화 서명 알고리즘(HS256, RS256 등)을 일관되게 고정하여 명시적으로 필터링하도록 교정하세요.
