# seam-log-injection (Seam 로그 인젝션 위험)

## 개요
JBoss Seam 프레임워크의 로깅 API가 표현식 언어(EL)를 지원하는 특성을 이용한 취약점을 탐지합니다.

## 위험성
*   **Log Injection / EL Injection**: 공격자가 입력값에 `#` 또는 `$` 표현식을 주입하여 시스템 중요 정보를 노출시키거나 임의 템플릿 실형을 유도할 수 있습니다.

## 조치 방안
*   로그 메시지에 사용자 입력을 바인딩할 때, 허용된 문자열만 포함하도록 검증하거나 로깅 시 표현식 인젝션 위험이 없는 API 레이어를 우회적용하세요.
