# command-injection-process-builder (프로세스 빌더 인젝션 경고)

## 개요
`ProcessBuilder` 실행 인자에 유저 동적 포매팅 문자열이 직접 가입되는 상태를 감지합니다.

## 위험성
*   공격자가 공백(` `)이나 특수 명령 기호(`;`, `|`)를 대입해 OS 주도 하의 임의 파괴적 커맨드 단일 실행을 트리거할 수 있습니다.

## 조치 방안
*   단일 문자열 실행이 아닌 가변인자 리스트 형식(`ProcessBuilder("cmd", "arg1", "arg2")`)으로 각 필드를 명시적 분할해 탑재해야 합니다.
