# tainted-cmd-from-http-request (HTTP 유입 커맨드 오염 감지)

## 개요
HttpServletRequest 등으로 들어온 동적 매개변수 유입이 수정 없이 곧바로 `ProcessBuilder` 등에 흐르는 것을 감시합니다.

## 위험성
*   사용자 통제가 미치기 힘든 인자 조작 영역을 파괴해 대규모 권한 탈취 및 임의 파일 탈취, 트래픽 유도가 원격에서 수 분 내 동작 가능합니다.

## 조치 방안
*   외부 데이터를 명령어 명칭 자체나 핵심 인자로 받지 마시고, 고유 ID 등으로 바인딩하여 백엔드에서 정적 커맨드에 매칭시켜 실행하십시오.
