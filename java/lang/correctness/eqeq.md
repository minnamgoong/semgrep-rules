# eqeq (자기 자신 비교 경고)

## 개요
$X == $X 또는 $X != $X 와 같이 본인 자신을 직접 비교하고 있습니다. 로직 실수이거나 무의미한 연산일 확률이 높습니다.

## 위험성
*   **논리 버그**: 타겟 변수를 오기입하여 원래 의도했던 비교 대상이 누락되었을 가능성이 매우 큽니다.
*   부동 소수점(`float`, `double`)의 경우 자기 자신 비교가 `NaN` 체크 목적일 수 있으나 일반 객체에서는 에러 확률이 높습니다.

## 조치 방안
*   비교 대상이 올바른 짝으로 매칭되었는지 변수명을 재검토하십시오.
