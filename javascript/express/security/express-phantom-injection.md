# express-phantom-injection (Phantom.js 인젝션 위험)

## 개요
phantom API 호출에 사용자 통제 입력 데이터가 결합되었습니다. SSRF 및 인젝션 예방을 위해 사전에 검증된 정적 화이트리스트 맵을 구비하세요.

## 위험성
*   **SSRF \ / Local File Read**: 웹 아카이브용 URL 탑재 시 공격자가 `file:///` 등의 로컬 주소를 주입해 파일 스크립팅 연계를 도모할 우려가 큽니다.

## 조치 방안
*   외부 변수가 가리키는 사이트 주소를 정적 도메인 허용 검증 단계를 통과시킵니다.
