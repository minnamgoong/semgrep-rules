# express-puppeteer-injection (Puppeteer 인젝션 방어)

## 개요
puppeteer 인스턴스 메서드 구동 영역에 외부 동적 데이터가 도출됩니다. SSRF 유도 및 원격 클라이언트 브라우저 구동 조작을 차단하십시오.

## 위험성
*   **SSRF / 로컬 페이지 탈취**: 서버 권한으로 내부 기동 중인 관리자 타겟 대시보드 스니핑, 혹은 `file:///` 유출 리스크가 상존 수위로 도사립니다.

## 조치 방안
*   페이지 조인 주소를 규격에 맞는 정적 맵 포인터로 검출해 로테이션 시키세요.
