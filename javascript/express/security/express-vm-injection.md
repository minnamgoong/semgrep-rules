# express-vm-injection (VM 모듈 인젝션 경보)

## 개요
Node.js vm 모듈 스크립트 실행 스택 등에 동적 사용자 오염 테두리가 가압되는 피로도를 잡습니다. 샌드박스 우회를 우려해 사전에 분리 차단하세요.

## 위험성
*   **샌드박스 우회를 통한 RCE**: `vm` 구동 환경은 가상 격리되나 특정 객체 프로토타입 조작(`__proto__`)으로 본 서버 쉘 명령을 격발시키는 심각한 유출 가능성이 항상 도사립니다.

## 조치 방안
*   유저 가변값을 스크립트 가동 핵심 유닛으로 넣지 마시고, 데이터 매개 변수를 사전 매핑하십시오.
