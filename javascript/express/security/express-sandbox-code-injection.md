# express-sandbox-code-injection (샌드박스 코드 인젝션 경보)

## 개요
Node.js 샌드박스 라이브러리(`sandbox` 등) 구동 시 동적 합체된 사용자 연산 버퍼를 대입하는 형태를 경보합니다.

## 위험성
*   **샌드박스 우회 및 RCE**: 샌드박스 환경이라 하더라도 특정 스택 오버플로우나 프로토타입 조작(`__proto__`)으로 부모 계층을 넘어 원격 쉘 실행이 가능해질 수 있습니다.

## 조치 방안
*   가변값을 스크립트 유닛으로 직접 탑재하지 마시고, 순수 데이터 객체 형태로만 샌드박스 컨텍스트에 바인딩하여 안전을 기하십시오.
