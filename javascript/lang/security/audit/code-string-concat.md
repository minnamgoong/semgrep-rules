# code-string-concat (동적 코드 실행 금지 경고)

## 개요
요청 데이터를 eval() 또는 Function() 실행 인자로 직접 연산 합사합니다. 원격 코드 실행(RCE) 타격을 유발하므로 동적 코드 실행을 금지하십시오.

## 위험성
*   **RCE (Remote Code Execution)**: 자바스크립트 엔진 문맥 제어를 통째로 내주게 되어 데이터베이스 파사드 및 본 서버 권한 덤핑이 실시간 가동됩니다.

## 조치 방안
*   해당 메서드를 교정 및 말소하고 안전한 JSON 파싱 등 정적 로직으로 회수하십시오.
