# deno-dangerous-run (Deno 커맨드 인젝션 경보)

## 개요
`Deno.run()` 메서드 실행 시 인자 전달부에 리터럴 문자열이 아닌 동적 연산 문자열이 가담하는 코드를 감지합니다.

## 위험성
*   **OS Command Injection**: 외부 입력값으로 명령어 인자를 구성하면 공격자가 스페이스(` `)나 특수기호를 통해 서버 OS 명령어를 권한 내에서 마음껏 제어할 수 있습니다.

## 조치 방안
*   가변적 문자열 결합을 배제하고, 인자들을 사전에 정의된 분할 배열(`["cmd", "arg1", "arg2"]`) 형태로 고정 탑재하십시오.
